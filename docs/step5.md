# STEP 5. 평가 세트와 채점 기준

## 평가 세트

고정 문제 10개는 명부 10개다. 각 50명이고, 한 세트를 통째로 프롬프트에 넣는다.

| 항목 | 값 |
|---|---|
| 파일 | `data/eval/set01.json` ~ `set10.json` |
| 세트당 인원 | 50명 |
| 세트당 명부 크기 | 약 10,200~10,700토큰 |
| 기록이 거의 빈 교인 | 세트당 5~7명 |

## 정답

`data/eval/answer_key.json`에 세트별로 들어 있다.

| 구분 | 인원 | 내용 |
|---|---|---|
| 반드시 포함 | 세트당 10명 | 급성 5명(최근 며칠~3주 사이 경조사·수술·사고) + 만성 5명(장기 입원·투석·발길 끊김) |
| 반드시 제외 | 세트당 5명 | 출석이 좋고 특이사항이 없으며 최근 심방을 다녀옴 |
| 판정 안 함 | 세트당 35명 | 무작위 |

top 10의 자리가 10개이고 반드시 포함도 10명이라 정답이 완전하다. 애매한 교인이 목록에
들어오면 그만큼 정답이 밀려나 자동으로 감점된다.

## 채점

### 통과/미달

하나라도 걸리면 탈락한다.

| 항목 | 기준 |
|---|---|
| 근거 사실성 | `reason`에 명부에 없는 사실을 단정한 것이 0개 |
| 한국어 | `reason`이 손보지 않고 쓸 수 있는 수준 |

### 통과선

10세트 합계로 본다.

| 항목 | 기준 |
|---|---|
| 포함 | 반드시 포함 100명 중 70명 이상이 top 10에 있을 것 |
| 제외 | 반드시 제외 50명 전원이 top 10에 없을 것 |

### 순위 결정

통과한 후보들 사이에서 위에서부터 비교한다.

1. **포함 수** (100점 만점)
2. **시점 판단** — 급성 5명이 만성 5명보다 위에 왔는가
3. **한국어 표현**
4. **응답 시간**
5. **VRAM 사용량**

## 실행

| 구분 | 횟수 |
|---|---|
| 본 채점 | 10세트 × 2후보 = 20회 |
| 목록 일관성 | set01을 5회씩 × 2후보 = 10회 |
| 합계 | 30회 |
