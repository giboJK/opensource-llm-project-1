# STEP 5. 평가 세트와 채점 기준

## 평가 세트

고정 문제 10개는 명부 10개다. 각 50명이고, 한 세트를 통째로 프롬프트에 넣는다.

| 항목 | 값 |
|---|---|
| 파일 | `data/eval/set01.json` ~ `set10.json` |
| 세트당 인원 | 50명 |
| 세트당 명부 크기 | 약 9,600~10,500토큰 |
| 기록이 거의 빈 교인 | 세트당 5~9명 |

시드가 고정돼 있어 다시 만들어도 같은 결과가 나온다.

```bash
uv run scripts/generate_eval_sets.py
```

## 정답

`data/eval/answer_key.json`에 세트별로 들어 있다.

| 구분 | 인원 | 내용 |
|---|---|---|
| 반드시 포함 | 세트당 5명 | 시점이 적힌 경조사·수술·입원 기록 |
| 반드시 제외 | 세트당 5명 | 출석이 좋고 특이사항이 없으며 최근 심방을 다녀옴 |
| 판정 안 함 | 세트당 40명 | 무작위 |

정답은 생성기가 심는다. 무작위로 만들어진 성인 중 10명을 골라 기록을 덮어쓰는 방식이라
가족관계와 기도제목이 그대로 남아 있고, 심은 인물만 따로 눈에 띄지 않는다.

심는 기록에는 사실만 적는다. "심방이 필요함" 같은 판단이 들어가면 모델이 명부에 적힌 답을
따라 읽게 되어 채점이 의미를 잃는다.

## 채점

### 통과/미달

하나라도 걸리면 탈락한다.

| 항목 | 기준 |
|---|---|
| 근거 사실성 | `reason`에 명부에 없는 사실을 단정한 것이 0개 |
| 한국어 | `reason`이 손보지 않고 쓸 수 있는 수준 |

### 통과선

10세트 합계로 본다.

| 항목 | 기준 |
|---|---|
| 포함 | 반드시 포함 50명 중 40명 이상이 top 10에 있을 것 |
| 제외 | 반드시 제외 50명 전원이 top 10에 없을 것 |

### 순위 결정

통과한 후보들 사이에서 위에서부터 비교한다.

1. **포함 수 + 제외 수** (100점 만점)
2. **시점 판단** — 지난주·2주 전 사건인 교인이 상위 5위 안에 왔는가
3. **한국어 표현**
4. **응답 시간**
5. **VRAM 사용량**

## 실행

| 구분 | 횟수 |
|---|---|
| 본 채점 | 10세트 × 2후보 = 20회 |
| 목록 일관성 | set01을 5회씩 × 2후보 = 10회 |
| 합계 | 30회 |
