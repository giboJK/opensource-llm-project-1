# STEP 2. 모델 요구사항 정의

명부를 받아 다음 7일 심방 대상 top 10을 순위와 근거로 낸다.

## 후보를 볼 때 확인할 정보

| 항목 | 우리 기준 |
|---|---|
| Language | 한국어 입출력 |
| Model Size | VRAM 7GB 이하, 전량 GPU 적재 |
| License | 교회 내부 업무 사용 가능 |
| Context Length | 16k 이상 |
| GPU | RTX 5060 Laptop, VRAM 8,151MiB |
| Task | 문서를 읽고 순위 목록을 JSON으로 출력 |

## 입력 크기

| 구분 | 값 |
|---|---|
| 명부 50명 | 약 10,200~10,700토큰 |
| 출력 10명 | 약 500~700토큰 |
| `num_ctx` | 16384 |

## 필수 통과 조건

하나라도 못 넘으면 탈락한다.

| 조건 | 기준 |
|---|---|
| 실행 | VRAM 7GB 이하, 전량 GPU 적재 (`ollama ps`) |
| License | Model Card 원문 확인 |
| 출력 형식 | `top10`에 10명. 각 항목에 `rank` `id` `name` `reason` |
| 명부 대조 | `id`가 명부에 있고 `name`이 그 `id`와 일치 |
| 중복 없음 | 같은 `id`가 두 번 나오지 않음 |
| 목록 일관성 | 5회 반복 시 10명 명단이 동일 (`temperature` 0) |
| 응답 시간 | 1회 60초 이내 |
| 한국어 | `reason`이 손보지 않고 쓸 수 있는 수준 |
| 근거 사실성 | `reason`에 명부에 없는 사실을 단정하지 않음 |
| 최소 품질 | STEP 5 채점 기준 통과 |

## 선호 우선순위

통과한 후보들 사이에서 위에서부터 본다.

1. **명단의 정확성** — 들어가야 할 교인이 있고, 들어가면 안 될 교인이 없는가
2. **순위의 타당성** — 지금 가야 할 교인이 위에 왔는가
3. **한국어 표현**
4. **응답 시간**
5. **VRAM 사용량**

한국어는 유창한데 명단이 틀리는 후보는 탈락이다.
