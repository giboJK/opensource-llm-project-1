# STEP 2. 모델 요구사항 정의

## 필수 통과 조건 (Must-pass)

반드시 만족해야 하는 조건과, 충족 여부를 "어떻게 확인할지"를 함께 적습니다.

| 조건 | 확인 방법 | 비고 |
|---|---|---|
| 수업용 노트북에서 실행 가능 | 다운로드 크기/필요 VRAM 확인 후 `ollama run`으로 실측 | |
| 사용 목적에 맞는 License | Model Card의 License 원문 확인 (상업적 사용 가능 여부 등) | |
| 필요한 입력/출력 길이 수용 | Context Length가 Use Case의 입력 문서/대화 길이를 수용하는지 | |
| 태스크에 필요한 최소 품질 | STEP 5에서 정할 채점 기준으로 (예: 평균 X점 이상) | 확정 시점: STEP 5 |

## 선호 우선순위 (Nice-to-have, 우선순위 순)

필수 조건을 충족한 후보들 사이에서 무엇을 먼저 볼지 순서대로 적습니다.

1. (예: 품질 — 정확성/한국어 표현)
2. (예: 전체 응답 시간)
3. (예: VRAM 사용량)

> 결과가 엇갈릴 때(예: A가 품질은 높지만 느림) 어떤 기준을 먼저 적용할지 미리 설명해두세요.

## 확정 시점

- STEP 5에서 질문/채점 기준을 정할 때 "필요한 점수/시간 기준"을 구체적인 숫자로 확정합니다.
- 확정된 기준은 두 로컬 후보에 동일하게 적용합니다.
