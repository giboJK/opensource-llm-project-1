# 평가 세트 데이터

전부 가상의 이름과 상황입니다. 실제 인물과 무관합니다.

`data/eval/set01.json` ~ `set10.json`, 각 50명. 정답은 `data/eval/answer_key.json`에 있습니다.

## 세트 하나의 구성

| 구분 | 인원 | 내용 |
|---|---|---|
| 반드시 포함 | 10명 | 급성 5명(최근 며칠~3주 사이 경조사·수술·사고) + 만성 5명(장기 입원·투석·발길 끊김) |
| 반드시 제외 | 5명 | 출석이 좋고 특이사항이 없으며 최근 심방을 다녀옴 |
| 판정 안 함 | 35명 | 1인 가구·부부·자녀가 있는 가정·3대 가정을 섞어 무작위 생성 |

심는 15명은 새로 만든 인물이 아닙니다. 무작위로 생성된 성인 중 15명을 골라 기록을 덮어쓴
것이라 가족관계와 기도제목이 그대로 남아 있습니다.

덮어쓰는 기록에는 사실만 적습니다. "심방이 필요함" 같은 판단이 들어가면 모델이 명부에 적힌
답을 따라 읽게 되어 채점이 의미를 잃습니다.

**ID**는 영문 대소문자와 숫자를 섞은 6자리입니다. 순번이 드러나면 앞에 있는 사람이 먼저
등록된 사람이라는 정보까지 모델에게 알려 주게 됩니다.

## 각 인물이 가진 정보

| 필드 | 내용 |
|---|---|
| 기본 정보 | 나이, 성별, 신앙 연차, 마지막 심방일, 최근 8주 출석, 건강 상태, 최근 경조사, 비고 |
| `family` / `family_note` | 세트 안의 가족관계(배우자·자녀·부모·조부모·손주), 없으면 사유 |
| `prayer_requests` | 기도제목. 인원당 평균 6개(최소 0, 최대 15). 내용·등록일·상태 |
| `visitation_records` | 최근 3년 심방 기록. `last_visitation_date`에서 평균 약 3개월 간격으로 역산 |
| `community_history` | 최근 3개년 소속 공동체. 연도별 0~2개(무소속 가능) |

## 정보 부족 교인

담당자 입력이 빠진 성도를 재현한 구간으로, 세트당 5~7명입니다. 절반은 출석까지 "정보 없음"이고,
나머지는 출석만 남고 건강·경조사·비고·심방·기도제목·소속이 비어 있습니다.

누가 여기 속하는지는 데이터에 적지 않습니다. 실제 교회 DB에 "이 사람 기록이 비었다"는 표시가
없는 것과 같습니다. 필요하면 이렇게 추립니다.

```python
cohort = [m["id"] for m in members
          if not m["prayer_requests"] and not m["visitation_records"]]
```

## 앞뒤가 맞도록 건 제약

- 소속 이력과 기도제목 등록일은 신앙 연차를 넘지 않습니다.
- 기도제목은 나이와 성별에 맞는 주제만 붙습니다. 8세에게 "취업/이직"이 붙지 않습니다.
- 무작위로 뽑는 건강·경조사·비고도 나이를 봅니다. 7세에게 "자녀 결혼", 2세에게 "손주 출생",
  0세에게 "가벼운 우울감"이 붙지 않습니다.
- 덮어쓰는 기록은 나이와 성별을 봅니다. 88세에게 "한 달 전 실직", 70세에게 "2주 전 출산"이
  붙지 않습니다.
- 공동체 소속은 만 4세부터 생깁니다. 2세에게 3년치 유치부 이력이 붙지 않습니다.
- 비고란에는 그 사람에 대한 사실만 적습니다. 데이터 설명이나 판단 지시는 넣지 않습니다.
- JSON 최상위에는 `communities`와 `members`만 있습니다. 정답은 파일 안에 넣지 않습니다.

## 소속 공동체

| 부서 | 공동체 |
|---|---|
| 교육부 | 유치부, 초등부, 중고등부, 대학청년부 |
| 행정부 | 재정팀, 홍보팀, 시설관리팀, 서기팀 |
| 봉사부 | 주방봉사팀, 안내팀, 찬양팀, 미디어팀 |

## 다시 생성하기

시드가 고정돼 있어 다시 돌려도 같은 결과가 나옵니다.

```powershell
uv run scripts/generate_eval_sets.py
```

세트 개수와 인원은 `--sets`, `--size`로 조절합니다. 가구 구성·기도제목·심방 기록을 만드는
부분은 `scripts/generate_sample_congregation.py`에 있고 `generate_eval_sets.py`가 가져다 씁니다.
